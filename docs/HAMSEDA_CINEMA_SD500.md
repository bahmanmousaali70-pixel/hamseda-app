# هم‌صدا سینما برای Owlenz SD500

## مشخصات و نصب
- برنامه مستقل Android با شناسه `com.roozhaye.cinema`؛ از برنامه اصلی هم‌صدا جداست.
- حداقل Android 9، هدف Android 9 و ABI سی‌ودوبیتی `armeabi-v7a`.
- رابط فارسی، افقی، تمام‌صفحه و قابل استفاده با کنترل/ریموت و کنترل گوشی.
- اتصال شبکه از اینترنت عادی پروژکتور انجام می‌شود؛ VPN یا پراکسی داخلی ندارد.

## جست‌وجوی واقعی درون برنامه
- جست‌وجوی مستقیم در Internet Archive Advanced Search API.
- نمایش فقط عنوان‌هایی که هم مجوز آزاد قابل قبول دارند و هم فایل ویدئویی مستقیم عمومی برای پخش دارند؛ عنوان و سال و نوع مجوز نشان داده می‌شود.
- برای هر نتیجه، دریافت Metadata API و بررسی مجوز و فایل‌های موجود.
- پخش مستقیم MP4/WebM فقط وقتی فراداده مجوزی مانند Public Domain، CC0، CC BY یا CC BY-SA را نشان دهد و فایل عمومی قابل پخش وجود داشته باشد.
- مجوزهای NonCommercial، NoDerivatives، All Rights Reserved یا مجوز نامشخص برای پخش مستقیم پذیرفته نمی‌شوند.
- نتیجه‌ای که فایل مستقیم یا مجوز روشن نداشته باشد از فهرست پخش حذف می‌شود.

## کنترل هم‌زمان از گوشی
- برنامه مستقل سینما روی پروژکتور یک سرور محلی HTTP روی پورت 8765 اجرا می‌کند.
- آدرس IP محلی و PIN شش‌رقمی جفت‌سازی روی صفحه پروژکتور نشان داده می‌شود.
- در تب سینمای برنامه اصلی هم‌صدا روی گوشی، IP و PIN وارد می‌شود؛ گوشی و پروژکتور باید در یک شبکه Wi-Fi باشند.
- جست‌وجو از گوشی به WebView پروژکتور ارسال می‌شود؛ نتیجه‌های قابل پخش از همان دستگاه به گوشی همگام می‌شوند و انتخاب «پخش» روی پروژکتور اجرا می‌شود.
- کنترل صفحه با تاچ‌پد، کلیک، کلیدهای جهت، انتخاب، بازگشت و اسکرول فراهم شده است.
- ارتباط در شبکه محلی است و به سرور ابری یا VPN وابسته نیست. PIN برای جفت‌سازی لازم است؛ توکن نشست در حافظه برنامه نگهداری می‌شود و با بستن برنامه از بین می‌رود.

## فیلتر نتیجه‌های قابل پخش
- نتایج جست‌وجو قبل از نمایش، از نظر فراداده مجوز و وجود فایل عمومی MP4/WebM بررسی می‌شوند.
- فقط مواردی نمایش داده می‌شوند که مجوز آزاد قابل قبول و فایل ویدئویی مستقیم پیدا شده باشد.
- این فیلتر در نسخه فعلی برای Internet Archive پیاده شده است؛ لینک‌های جست‌وجوی سایت‌های ایرانی هنوز کاتالوگ تجمیعی و تشخیص خودکار پخش‌پذیری ندارند.

## منابع ایرانی
- آپارات: جست‌وجوی وب محدود به دامنه aparat.com.
- نماشا: جست‌وجوی وب محدود به دامنه namasha.com.
- تلوبیون: جست‌وجوی وب محدود به دامنه telewebion.com.
- سپهر: جست‌وجوی وب محدود به دامنه sepehrtv.ir.
- تماشاخونه: جست‌وجوی وب محدود به دامنه tmk.ir؛ رایگان بودن هر عنوان باید جداگانه بررسی شود.

این منابع در نسخه فعلی از طریق صفحه جست‌وجوی وب باز می‌شوند؛ هنوز API اختصاصی یا فهرست نتایج یکپارچه درون‌برنامه‌ای برای آن‌ها پیاده نشده است. پخش صفحه وب یا ویدئوی تعبیه‌شده هر سرویس به اجازه embed، ورود مجاز و سازگاری WebView بستگی دارد.

## محدودیت‌های مهم
- «رایگان» بودن یک پلتفرم به معنی رایگان بودن تمام فیلم‌ها و سریال‌های آن نیست.
- اشتراک، ورود، DRM، محدودیت منطقه‌ای و حقوق پخش دور زده نمی‌شوند.
- هیچ تضمینی برای دسترسی همه سایت‌ها از همه اپراتورهای اینترنت ایران وجود ندارد.
- جست‌وجو در Internet Archive به تنهایی تضمین‌کننده کیفیت، زبان فارسی، دوبله یا مناسب‌بودن محتوای هر عنوان نیست؛ مجوز و فایل برای هر نتیجه بررسی می‌شود.
- تست نهایی نصب و پخش روی خود دستگاه Owlenz SD500 باید پس از دریافت APK انجام شود.

## گام‌های بعدی
1. تست نصب، کنترل ریموت، جست‌وجو و پخش روی SD500 واقعی.
2. بررسی شرایط رسمی API/embed برای هر سرویس ایرانی و افزودن فقط اتصال مجاز.
3. افزودن کاتالوگ تجمیعی برای منابعی که API رسمی یا مجوز دسترسی مجاز دارند.
4. افزودن حساب/اشتراک فقط برای محتوایی که حق پخش آن متعلق به هم‌صداست.
