# هم‌صدا سینما برای Owlenz SD500

## وضعیت نسخه آزمایشی
این برنامه یک Android application مستقل با شناسه `com.roozhaye.cinema` است و از ماژول اصلی هم‌صدا جداست. حداقل Android 9 و ABI سی‌ودوبیتی `armeabi-v7a` را هدف می‌گیرد تا با مشخصات گزارش‌شده SD500 سازگار باشد.

## منابع جست‌وجو
- آپارات: جست‌وجوی وب محدود به دامنه aparat.com
- نماشا: جست‌وجوی وب محدود به دامنه namasha.com
- تلوبیون: جست‌وجوی وب محدود به دامنه telewebion.com
- سپهر: جست‌وجوی وب محدود به دامنه sepehrtv.ir
- تماشاخونه: جست‌وجوی وب محدود به دامنه tmk.ir؛ رایگان بودن هر عنوان باید بررسی شود.
- Internet Archive: جست‌وجوی آثار عمومی و دارای مجوز آزاد.

جست‌وجوی کلی با یک عبارت چنددامنه‌ای انجام می‌شود؛ هر منبع همچنین مسیر جست‌وجوی مستقل دارد. این نسخه هنوز API اختصاصی یا فهرست نتایج یکپارچه و قابل‌فیلتر از سرویس‌ها ندارد.

## پخش
پخش‌کننده HTML5 فقط لینک مستقیم HTTP(S) با پسوند MP4، M3U8 یا WebM را می‌پذیرد. پخش درون‌برنامه‌ای صفحه‌های وب سرویس‌ها به مجوز embed و سازگاری WebView آن سرویس بستگی دارد. DRM، ورود/اشتراک، محدودیت منطقه‌ای یا دسترسی غیرمجاز دور زده نمی‌شود.

## شبکه
هیچ VPN یا پروکسی سراسری به برنامه افزوده نشده است. درخواست‌ها از اینترنت عادی خود پروژکتور انجام می‌شوند؛ بنابراین فقط منابعی کار می‌کنند که از اتصال ایران قابل دسترسی باشند.

## گام‌های بعدی
1. تکمیل تست نصب و اجرا روی SD500 واقعی.
2. بررسی رسمی API/embed و شرایط استفاده هر سرویس.
3. افزودن کاتالوگ تجمیعی فقط برای منابعی که API یا مجوز دسترسی مجاز دارند.
4. افزودن حساب کاربری/اشتراک فقط برای محتوای دارای حقوق پخش هم‌صدا.
